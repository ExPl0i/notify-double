First release with a signed APK: future versions install over this one and keep your settings.

### What's new

- English interface; Russian stays for phones set to Russian. The log and event descriptions follow the phone's language too.
- English README; the Russian guide moved to `README.ru.md`.
- Releases are now built and signed by GitHub Actions.

### Upgrading from a build made in Android Studio

That build is signed with a different key, so Android will not install this APK over it. Uninstall the old app first, then repeat the setup: choose the iPhone, turn off battery optimization, press Start, turn the app on in Mi Fitness and allow your iPhone apps again. The Bluetooth pairing with the iPhone stays.
